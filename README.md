hypeHero
========

Replaces the owner block with a full-width cover hero image for profiles and groups.

![Elgg 7.x](https://img.shields.io/badge/Elgg-7.x-orange.svg?style=flat-square)

## Compatibility

| Plugin version | Elgg version |
|---|---|
| 7.0.0   | 7.x  |
| 6.0.0   | 6.x  |
| 5.0.0   | 5.x  |
| 4.0.0   | 4.x  |
